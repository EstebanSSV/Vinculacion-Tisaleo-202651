# Guía para colaborar

El equipo trabajará con cambios pequeños y revisables:

1. Tomar una tarea acordada y describir el resultado esperado.
2. Crear una rama para esa tarea desde `main`.
3. Abrir un pull request que explique qué cambió y cómo se comprobó.
4. Pedir revisión a otra persona del equipo antes de integrar el cambio.
5. Actualizar la documentación cuando cambie un flujo o una decisión aprobada.

Antes de dar una tarea por terminada, comprobar sus criterios de aceptación y conservar la evidencia de prueba o validación pertinente. Los datos de un emprendimiento no deben aparecer en la cuenta de otro. Las ventas, el stock y los resúmenes deben coincidir.

No incluir contraseñas, claves, datos personales reales ni archivos de configuración privados en el repositorio. Usar datos de ejemplo para desarrollo y pruebas.
