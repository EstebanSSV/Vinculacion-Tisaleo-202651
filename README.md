# Vinculación Tisaleo 202651

Proyecto de vinculación de Ingeniería de Software para apoyar a los emprendimientos del cantón Tisaleo. El equipo desarrollará un sistema web sencillo para organizar productos, existencias, ventas internas y resúmenes del negocio.

## Qué incluirá

- Acceso de emprendedores y personal técnico de la ESPE, con información separada por emprendimiento.
- Perfil del negocio y catálogo de productos y servicios.
- Control de inventario con entradas, salidas, historial de movimientos y alertas de stock bajo.
- Registro manual de ventas, anulaciones y devoluciones. El medio de cobro se registra como efectivo o transferencia directa; el sistema no procesa pagos.
- Resúmenes de ventas, ingresos y existencias.

## Plan de trabajo

| Entrega | Semanas | Resultado esperado |
| --- | --- | --- |
| V1.0 | 1–9 | Requisitos validados, acceso, perfil, catálogo e inventario. |
| V2.0 | 10–13 | Ventas internas, resúmenes y versión en servidor de pruebas. |
| V3.0 | 15–17 | Pruebas, capacitación, ajustes y entrega final. |

La semana 14 es un receso institucional. El plan está sujeto a la validación del tutor y los beneficiarios.
