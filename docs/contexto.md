# Contexto del proyecto

El proyecto busca que los emprendimientos de Tisaleo lleven un control básico de su actividad comercial. El sistema contempla cinco áreas:

1. **Usuarios y emprendimientos:** inicio de sesión, recuperación de acceso, permisos y datos del negocio.
2. **Catálogo:** productos y servicios, categorías, precios, unidades de medida y estado activo o inactivo.
3. **Inventario:** entradas, salidas justificadas, ajustes, kardex y alertas de stock mínimo.
4. **Ventas internas:** registro manual, descuento de existencias y reversión de ventas erróneas o devoluciones.
5. **Resúmenes:** unidades vendidas, ingresos por periodo y medio de cobro, productos destacados, stock y valoración de inventario.

El sistema registra ventas ya realizadas de forma presencial, por teléfono o por WhatsApp. No contempla pasarela de pago, cobros automáticos, pedidos, facturación electrónica ni integración bancaria.
